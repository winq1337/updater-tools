## 💡 О проекте

`updater-tools` решает распространенные проблемы при администрировании Linux-серверов:
- Зависание зеркал APT при попытке резолва через IPv6 (`Connecting to archive.ubuntu.com...`).
- Блокировки базы `dpkg` фоновыми службами (`unattended-upgrades`, `lock-frontend`).
- Простой и несвоевременное обновление веб-серверов (Nginx, Apache, PHP-FPM) при появлении критических CVE.
- Интерактивные всплывающие окна DPKG, останавливающие автоматизацию.

---

## 🚀 Ключевые возможности

1. **Watchdog защиты от зависания APT**:
   - Автоматический контроль времени выполнения операций APT.
   - При обнаружении зависания скрипт мягко прерывает операцию и переключает сетевой стек на чистый IPv4 (`Acquire::ForceIPv4 "true"`).
2. **Умное снятие блокировок DPKG**:
   - Двухэтапное завершение блокирующих процессов: сначала отправка `SIGTERM`, при отсутствии реакции через тайм-аут — `SIGKILL (-9)`.
   - Автоматическая очистка заблокированных `.lock`-файлов и восстановление базы через `dpkg --configure -a`.
3. **Глубокий автодетект и обновление сервисов**:
   - **Nginx**: подключение репозитория производителя для оперативного получения security-патчей, синтаксический тест `nginx -t` и рестарт.
   - **Apache2**: проверка синтаксиса `apache2ctl configtest` и обновление.
   - **PHP & PHP-FPM**: обнаружение установленных версий, обновление пакетов и перезапуск служб `php*-fpm`.
   - **Docker / PM2 / Certbot**: регламентная очистка кэша и проверка SSL-сертификатов.
4. **Безопасность**:
   - Создание резервной копии директорий `/etc/nginx`, `/etc/apache2`, `/etc/php`, `/etc/mysql`, `/etc/docker` перед стартом.
   - Проверка наличия свободного места на диске (минимум 2 GB).
   - Финальный аудит открытых портов (LISTEN) и проверка необходимости перезагрузки ядра (`reboot-required`).

## 📦 Быстрая установка

Запуск в одну строку:

```bash
curl -4 -fsSL https://raw.githubusercontent.com/winq1337/updater-tools/main/install.sh | sudo bash
```

После установки утилита доступна глобально:

```bash
sudo updater-tools
```

---

## 🛠 Ручной запуск и опции

Склонируйте репозиторий и запустите скрипт:

```bash
git clone https://github.com/winq1337/updater-tools.git
cd updater-tools
chmod +x updater-tools.sh
sudo ./updater-tools.sh
```

### Поддерживаемые флаги:

| Флаг | Описание |
|---|---|
| `-d`, `--dry-run` | Тестовый запуск без внесения изменений в систему |
| `-v`, `--verbose` | Вывод расширенного потока отладочных сообщений |
| `-b`, `--no-backup` | Пропустить создание бэкапа конфигурационных файлов |
| `-h`, `--help` | Показать справочное руководство |
